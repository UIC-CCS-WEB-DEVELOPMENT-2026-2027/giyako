# Giyako Social Platform

> **A Multi-University Student Interest-Logging & Social Timeline Network**  

---

## 📌 About the Project

Students across all year levels face changing social and academic needs—from lowerclassmen making initial friends to upperclassmen searching for capstone project collaborators or niche hobby partners. Existing platforms are often cluttered, unverified, and lack campus-restricted privacy controls or structured interest logging.

**Giyako** is a multi-tenant, responsive web application where verified students log their academic pursuits, current courses, research projects, media, and personal hobbies It replaces cold messaging with context-rich interactions directly tied to logged entries

---

## ✨ Key Features

* **Structured Interest-Logging:** Log active courses, capstone topics, reading lists, media backlogs, and hobbies in a visual, Letterboxd/Backloggd-style format
* **Connected Campus Timeline & Tag Filters:** Discover live campus activity feeds filtered by interest tags (e.g., `#BiologyResearch`, `#EcoHiking`, `#GuitarJam`)
* **Profile Analytics:** Track academic vs. personal logging distributions through Storygraph-style analytics charts
---
